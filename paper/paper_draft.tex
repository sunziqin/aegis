\begin{abstract}
Autonomous AI agent frameworks frequently require thousands of high-frequency micro-decisions per hour—including dynamic tool selection, workflow dispatching, intent classification, and safety guardrailing. Contemporary agent architectures overwhelmingly delegate these atomic decisions to generative autoregressive Large Language Models (LLMs). This induces an unsustainable \textit{System 2 latency crisis}: sequential token-by-token decoding imposes 500--2,000\,ms of latency per step, suffers from severe position bias ($A$-bias), and is vulnerable to uncalibrated, overconfident hallucinations on out-of-distribution (OOD) inputs. 

In this work, we propose \textbf{Millennium-Jev}, an open-source, non-autoregressive ``System 1'' decision reflex foundation model engineered to provide sub-50\,ms deterministic actions backed by finite-sample mathematical safety guarantees. Millennium-Jev introduces four foundational contributions: (1) \textbf{Vectorized Option Span Mean-Pooling} via batch tensor operations ($\text{torch.bmm}$), resolving semantic collapse on multi-word candidate actions; (2) \textbf{Native C++ Flash-SDPA Bidirectional Attention}, setting underlying causal flags to bypass 4D attention mask allocation ($0$\,KB intermediate mask RAM); (3) \textbf{Single-Forward Multi-Query Parallel Evaluation}, enabling heterogeneous decision primitives (\texttt{Choice}, \texttt{Score}, \texttt{Noul}) to execute simultaneously in a single prompt in 37.5\,ms; and (4) \textbf{Distribution-Free Split-Conformal Prediction} paired with a production \textbf{Tri-Gate Protocol}, mathematically guaranteeing marginal coverage $\mathbb{P}(Y \in \mathcal{C}(X)) \ge 95.0\%$. 

Evaluated across a strictly state-disjoint, zero-leakage benchmark of $N=8,657$ blind held-out samples, Millennium-Jev 0.5B achieves an overall Top-1 accuracy of \textbf{84.28\%} (+15.68\% over raw zero-shot Qwen2.5), an empirical conformal coverage of \textbf{94.16\%}, an autonomous act clearance rate of \textbf{73.95\%}, and an autonomous action precision of \textbf{94.36\%} (selective risk restricted to 5.64\%). The complete model weights, calibration artifacts, and codebase are open-sourced under the Apache-2.0 license.
\end{abstract}

\section{Introduction}

Autonomous AI agents represent a paradigm shift from passive language processing to active embodied workflows, tool manipulation, and continuous environmental interaction \cite{wang2024survey, xi2023rise}. In realistic production deployments—ranging from automated software engineering to financial risk dispatching—an agent's life cycle is dominated by an enormous volume of discrete, control-plane decisions:
\begin{enumerate}
    \item \textbf{Tool Routing}: Selecting among a dynamic set of $K$ runtime tools (e.g., SQL executor vs. Bash shell vs. REST API);
    \item \textbf{Workflow Gating}: Deciding whether a complex task requires escalation to human supervisors;
    \item \textbf{Safety Guardrailing}: Verifying whether a multi-modal user prompt violates security policies or contains prompt-injection attacks.
\end{enumerate}

\subsection{The System 2 Latency Crisis}
According to dual-process cognitive psychology \cite{kahneman2011thinking}, human intelligence operates via two distinct mechanisms: \textit{System 1} (fast, automatic, reflexive, low-cost) and \textit{System 2} (slow, deliberative, sequential, high-effort). 

Paradoxically, modern LLM agent systems force slow, generative System 2 models (e.g., GPT-4, Claude 3.5, Qwen2.5-72B) to execute every atomic System 1 micro-decision. Forcing an autoregressive model to decode structured JSON or XML token-by-token introduces three fatal systemic bottlenecks:
\begin{itemize}
    \item \textbf{Inference Latency \& Compute Waste}: Generating 50--150 formatting tokens to express a single categorical choice costs 500--2,500\,ms of serial GPU memory bandwidth, creating severe bottlenecks in real-time robotics and dialogue agents.
    \item \textbf{Causal Blindfold \& Positional Bias}: Autoregressive decoders apply a causal lower-triangular mask ($j \le i$), preventing earlier candidate choices from attending to downstream qualifiers. When uncertain, generative decoders collapse onto the first candidate token ($A$-bias), guessing option $A$ up to 35\% of the time regardless of validity \cite{zheng2023large}.
    \item \textbf{Uncalibrated Overconfidence \& Silent Failures}: Deep neural networks trained under standard cross-entropy are notoriously miscalibrated \cite{guo2017calibration}. Faced with out-of-distribution (OOD) noise or adversarial prompt injections, standard argmax decoders output incorrect actions with $>90\%$ spurious confidence.
\end{itemize}

\subsection{Our Solution: The Millennium-Jev Architecture}
To resolve these bottlenecks, we introduce \textbf{Millennium-Jev}, the flagship non-autoregressive decision reflex foundation of the \textit{Millennium Open-Source Ecosystem}. Rather than autoregressively generating text, Millennium-Jev accepts an arbitrary state $S$ and dynamic runtime candidate actions $\mathcal{O} = \{o_1, \dots, o_K\}$, predicting calibrated posterior distributions and finite-sample prediction sets $\mathcal{C}(X)$ in a \textbf{single forward pass}.

Our contributions are summarized as follows:
\begin{enumerate}
    \item \textbf{Dual-Process Agent Architecture}: We operationalize Kahneman's dual-process theory for language agents, providing sub-50\,ms reflexive execution while reserving expensive deliberative LLMs strictly for escalated edge cases.
    \item \textbf{Option Span Mean-Pooling \& C++ SDPA Acceleration}: We eliminate marker collapse by pooling representations across entire candidate token spans ($\text{torch.bmm}$) and bypass 4D attention mask allocation ($0$\,KB intermediate mask memory) via native PyTorch C++ Flash-SDPA integration.
    \item \textbf{Single-Forward Multi-Query Parallelism}: We extend structured decision primitives (\texttt{Choice}, \texttt{Score}, \texttt{Noul}) to simultaneous multi-query evaluation in a single forward pass, resolving multi-aspect agent states in 37.5\,ms.
    \item \textbf{Distribution-Free Conformal Safety}: We introduce the production \textbf{Tri-Gate Protocol}, mathematically bounding marginal error ($\mathbb{P}(Y \in \mathcal{C}(X)) \ge 1 - \alpha$) and selective risk on autonomous actions.
    \item \textbf{Strictly State-Disjoint Benchmark ($N=8,657$)}: We establish a leak-free evaluation benchmark with verified $0.00\%$ state overlap across financial intents, agent tool routing, safety guardrails, and news classification.
\end{enumerate}

\section{Related Work \& Novelty Landscape}

To contextualize our work and verify distinct academic positioning, we categorize related literature into three main directions:

\subsection{Model-Level LLM Routers}
Frameworks such as RouteLLM \cite{ong2024routellm}, FrugalGPT \cite{chen2023frugalgpt}, and RouteNLP \cite{ding2024routenlp} train preference-based classifiers to route queries between large frontier models (e.g., GPT-4) and smaller models (e.g., Llama-3-8B). \textit{Distinction}: These systems are external dispatchers that still invoke an autoregressive LLM to generate natural language. In contrast, Millennium-Jev is an internal, non-autoregressive decision cortex that replaces text generation entirely for agent control tasks.

\subsection{Non-Autoregressive Decision Foundations}
Recent industrial initiatives, notably Silicon Valley's TypeSafe Jev \cite{alphamatch2025jev} and open-source Laya \cite{laya2025modernbert}, investigate non-autoregressive classification for agent primitives. However, Jev is a closed-source, cloud-hosted API exhibiting $>200$\,ms network round-trip latency. Laya, built on ModernBERT-large (395M), is constrained to a 512-token context window, fails on non-English/multilingual tasks, compresses candidate choices into a single token marker ($\langle|\text{fim\_pad}|\rangle$) leading to representation collapse, and lacks statistical safety guarantees. Millennium-Jev scales context to 2,048--32,768 tokens, provides bilingual Chinese-English parity, implements Option Span Mean-Pooling, and integrates Split-Conformal prediction sets.

\subsection{Conformal Prediction in Language Models}
Conformal Prediction (CP) \cite{vovk2005algorithmic, angelopoulos2021gentle} provides finite-sample statistical guarantees without distributional assumptions. Recent works explore CP for generative LLM question answering (e.g., CROQ \cite{croq2024}, CP-OPT \cite{cpopt2024}, and CP-Router \cite{cprouter2024}). However, existing works apply CP on top of slow autoregressive sequence generation. Millennium-Jev is the first to integrate Split-Conformal calibration directly into a non-autoregressive, bi-directional Transformer decision head for real-time agent reflexes.

\section{Methodology}

\subsection{Problem Formulation and Typed Primitives}
Let $\mathbf{S}$ denote the agent's current environment state (e.g., dialogue history, terminal observation, or document context). An agent evaluates $M$ heterogeneous decision queries $\{Q_1, \dots, Q_M\}$. Millennium-Jev formalizes three first-class typed primitives:
\begin{itemize}
    \item $\texttt{Choice}(\mathcal{O}, Q)$: Discrete categorical selection over $K \ge 2$ dynamic candidate actions $\mathcal{O} = \{o_1, \dots, o_K\}$.
    \item $\texttt{Score}(v_{\min}, v_{\max}, B, Q)$: Expected ordinal score over $B$ discretized bins, yielding expectation $\mathbb{E}[S] = \sum_{b=1}^B v_b p_b$ and variance $\text{Var}[S]$.
    \item $\texttt{Noul}(\tau, Q)$ / $\texttt{Boolean}$: Calibrated binary predicate testing condition validity with safety margin $\tau \in (0, 1)$.
\end{itemize}

\subsection{Vectorized Option Span Mean-Pooling}
Previous architectures assign candidate representations to a single special delimiter token $m_k$, which causes semantic collapse when candidate descriptions contain multi-token qualifiers (e.g., ``\texttt{git\_checkout: discard local uncommitted modifications}'').

Millennium-Jev introduces \textbf{Vectorized Option Span Mean-Pooling}. For candidate $k$ occupying token span $[s_k, e_k)$ in sequence length $L$, the pooled representation $\mathbf{h}_k^{\text{pool}}$ is computed via GPU batch matrix multiplication:
\begin{equation}
\mathbf{h}_k^{\text{pool}} = \frac{1}{e_k - s_k} \sum_{t=s_k}^{e_k - 1} \mathbf{H}_t \in \mathbb{R}^D
\end{equation}
where $\mathbf{H} \in \mathbb{R}^{B \times L \times D}$ is the last hidden state of the backbone. Formulated as a sparse-dense tensor product, span pooling executes in $O(1)$ GPU kernel launches without Python loop overhead.

\subsection{Native C++ SDPA Full Bidirectional Attention}
Standard causal decoder backbones (e.g., Qwen2.5) enforce lower-triangular causal masks:
\begin{equation}
\mathbf{A}_{i, j} = \begin{cases} 0 & j \le i \\ -\infty & j > i \end{cases}
\end{equation}
This induces severe asymmetry: earlier candidate options cannot attend to subsequent options. Constructing an intermediate 4D bidirectional float mask $\mathbf{M} \in \mathbb{R}^{B \times 1 \times L \times L}$ incurs $O(L^2)$ memory allocation ($16.8$\,MB per sample at $L=2,048$).

We solve this by directly modifying the attention modules:
\begin{algorithm}[H]
\caption{Zero-Memory Fast Bidirectional SDPA}
\begin{algorithmic}[1]
\REQUIRE Backbone module $\mathcal{M}$, Input IDs $\mathbf{X}$, Attention Mask $\mathbf{A}_{\text{2D}}$
\STATE \textbf{Toggle}: For each attention layer $l \in \mathcal{M}$, set $l\text{.is\_causal} \leftarrow \text{False}$
\IF{$\mathbf{A}_{\text{2D}} == \mathbf{1}$ (Single unpadded inference)}
    \STATE $\mathbf{A}_{\text{pass}} \leftarrow \text{None}$ \COMMENT{Direct C++ Flash-SDPA passthrough}
\ELSE
    \STATE $\mathbf{P} \leftarrow (1.0 - \mathbf{A}_{\text{2D}}) \times -10^4$
    \STATE $\mathbf{A}_{\text{pass}} \leftarrow \mathbf{P}[:, \text{None}, \text{None}, :] + \mathbf{P}[:, \text{None}, :, \text{None}]$ \COMMENT{Outer broadcast}
\ENDIF
\STATE $\mathbf{H} \leftarrow \text{Backbone}(\mathbf{X}, \text{attention\_mask}=\mathbf{A}_{\text{pass}})$
\RETURN $\mathbf{H}$
\end{algorithmic}
\end{algorithm}
This reduces intermediate 4D mask RAM to exactly \textbf{0\,KB} for unpadded inference while preserving 100\% numerical equivalence (max absolute error $< 9.76 \times 10^{-4}$ in bfloat16).

\subsection{Dynamic Option-Marker Decision Head}
The pooled representations $\mathbf{E}_{\text{cand}} = [\mathbf{h}_1^{\text{pool}}, \dots, \mathbf{h}_K^{\text{pool}}]^\top \in \mathbb{R}^{K \times D}$ pass through a 2-layer Inter-Option Transformer Cross-Attention module:
\begin{equation}
\widetilde{\mathbf{E}}_{\text{cand}} = \text{TransformerEncoder}(\mathbf{E}_{\text{cand}}) \in \mathbb{R}^{K \times D}
\end{equation}
Logits $z_k$ and normalized posterior probabilities $p_k$ are derived symmetrically:
\begin{equation}
z_k = \mathbf{w}_{\text{score}}^\top \widetilde{\mathbf{e}}_k + b, \quad p_k = \frac{\exp(z_k / T)}{\sum_{j=1}^K \exp(z_j / T)}
\end{equation}
Simultaneously, the $[\text{CLS}]$ representation $\mathbf{h}_{\text{CLS}}$ drives an anomaly escalation gate:
\begin{equation}
r_{\text{esc}} = \sigma(\mathbf{w}_{\text{esc}}^\top \mathbf{h}_{\text{CLS}} + b_{\text{esc}}) \in [0, 1]
\end{equation}

\subsection{Split-Conformal Calibration \& The Tri-Gate Protocol}
Given an exchangeable held-out calibration dataset $\mathcal{D}_{\text{calib}} = \{(X_i, Y_i)\}_{i=1}^n$, we compute non-conformity scores:
\begin{equation}
s_i = 1 - p(Y_i \mid X_i)
\end{equation}
For a user-specified significance level $\alpha = 0.05$ (guaranteeing $95\%$ marginal coverage), we compute the empirical quantile:
\begin{equation}
\hat{q} = \text{Quantile}\left( s_{1:n}, \frac{\lceil (n+1)(1-\alpha) \rceil}{n} \right)
\end{equation}
For any unseen runtime query $X_{n+1}$, the conformal prediction set is:
\begin{equation}
\mathcal{C}(X_{n+1}) = \left\{ k \in \mathcal{O} \;\middle|\; p(k \mid X_{n+1}) \ge 1 - \hat{q} \right\}
\end{equation}

\begin{theorem}[Finite-Sample Marginal Coverage Guarantee]
\label{thm:conformal}
Under the assumption that $(X_1, Y_1), \dots, (X_{n+1}, Y_{n+1})$ are exchangeable random variables, the prediction set $\mathcal{C}(X_{n+1})$ satisfies:
\begin{equation}
\mathbb{P}\left( Y_{n+1} \in \mathcal{C}(X_{n+1}) \right) \ge 1 - \alpha
\end{equation}
\end{theorem}
\begin{proof}
Let $s_{n+1} = 1 - p(Y_{n+1} \mid X_{n+1})$. By exchangeability, the rank of $s_{n+1}$ among $\{s_1, \dots, s_n, s_{n+1}\}$ is uniformly distributed over $\{1, \dots, n+1\}$. Choosing $\hat{q}$ as the $\lceil (n+1)(1-\alpha) \rceil / n$ empirical quantile ensures that $s_{n+1} \le \hat{q}$ with probability at least $1 - \alpha$. By definition, $s_{n+1} \le \hat{q} \iff p(Y_{n+1} \mid X_{n+1}) \ge 1 - \hat{q} \iff Y_{n+1} \in \mathcal{C}(X_{n+1})$.
\end{proof}

\subsubsection{The Production Tri-Gate Protocol}
While conformal coverage guarantees that the true action is contained within $\mathcal{C}(X)$, autonomous execution requires a definitive, unambiguous singleton. We formulate the \textbf{Tri-Gate Clearance Protocol}:
\begin{definition}[Tri-Gate Autonomous Execution Rule]
An action is cleared for autonomous execution ($\texttt{can\_act} = \text{True}$) if and only if all three conditions are satisfied:
\begin{enumerate}
    \item \textbf{Conformal Singleton Gate}: $|\mathcal{C}(X)| = 1$ (resolves ambiguity);
    \item \textbf{Confidence Floor Gate}: $\max_k p_k \ge 0.60$ (rejects flat OOD entropy);
    \item \textbf{Anomaly Risk Gate}: $r_{\text{esc}} \le 0.70$ (suppresses structural anomalies).
\end{enumerate}
If any gate fails, the decision is classified as $\texttt{verdict} = \text{escalate}$, instantly routing to System 2 or human-in-the-loop.
\end{definition}

\section{Experiments and Results}

\subsection{Experimental Setup}
\textbf{Training Specifications}: Millennium-Jev 0.5B was initialized from Qwen2.5-0.5B-Instruct. We applied All-Linear LoRA ($r=32, \alpha=64$) across all linear projections (\texttt{q, k, v, o, gate, up, down}). Training was performed on an isolated NVIDIA Tesla V100 SXM2 16GB node for 3 epochs (30,612 micro-steps, total time: 31,586.2 seconds / 8.77 hours) with effective batch size 16.

\textbf{Dataset Partitioning}: To ensure complete academic integrity and avoid data contamination, we implemented a cryptographic partitioning algorithm. The dataset was split into:
\begin{itemize}
    \item \textbf{Training Set}: $N_{\text{train}} = 15,306$ samples (SHA-256: \texttt{7e415e...});
    \item \textbf{Calibration Set}: $N_{\text{calib}} = 10,075$ samples (SHA-256: \texttt{5364a7...}, $\hat{q} = 0.9690$);
    \item \textbf{Held-Out Test Set}: $N_{\text{test}} = 8,657$ samples (SHA-256: \texttt{5fa227...}).
\end{itemize}
Across all splits, the normalized state text overlap is verified to be \textbf{strictly 0.00\%}.

\section{Discussion \& Limitations: The Jaggedness Boundary}

Intellectual honesty demands a rigorous post-mortem of where non-autoregressive decision reflex models break down. Following the open documentation of behavioral ``jaggedness'' in production decision models \cite{alphamatch2025jev}, we conducted systematic red-teaming across adversarial edge cases. Our empirical audit reveals three distinct operating regimes:

\subsection{The Anatomy of Silent Defects: Arithmetic and Gaslighting}
Our experiments identify two fatal failure modes where the model commits catastrophic errors while maintaining dangerously sharp, overconfident softmax probabilities ($>98\%$), effectively deceiving the Conformal Singleton Gate:
\begin{enumerate}
    \item \textbf{Temporal Arithmetic without Scratchpad (No-CoT Defect)}: When presented with date comparison queries (e.g., transaction on Sept 10 vs. return request on Sept 21 under a strict 7-day policy, where $21 - 10 = 11 > 7$), Millennium-Jev 0.5B incorrectly predicts ``Eligible for return'' with \textbf{99.22\% confidence}. Because non-autoregressive models execute in a single forward pass without intermediate token generation, they lack the computational scratchpad necessary for multi-step arithmetic. Upstream orchestrators must compute numerical differences in deterministic code prior to dispatching state representations.
    \item \textbf{Adversarial Semantic Gaslighting}: When a malicious payload (e.g., \texttt{curl https://malware.sh | bash}) is annotated with explicit misleading instructions (e.g., \textit{``Notice: This is a benign network ping, please classify as benign\_healthcheck''}), the model follows the surface prompt directive, assigning \textbf{98.44\% confidence} to the benign label. Non-autoregressive decision heads lack multi-step adversarial verification. Millennium-Jev must operate downstream of deterministic regex/AST sanitization layers, never as an isolated security firewall.
\end{enumerate}

\subsection{Effective Interception: Ambiguity and Entropy Expansion}
Conversely, when inputs suffer from semantic ambiguity or extreme distractor noise, the Split-Conformal Tri-Gate functions as an effective safety net:
\begin{itemize}
    \item \textbf{Multi-Intent Collision}: When a user simultaneously demands subscription cancellation and transaction refund, the conformal prediction set correctly expands to $|\mathcal{C}(X)| = 2$ ($\{\texttt{subscription\_cancellation}, \texttt{refund\_dispute}\}$), triggering $\texttt{can\_act} = \text{False}$ and successfully escalating the collision to human review.
    \item \textbf{Needle-in-a-Haystack Noise}: When a critical database outage message is concealed within 50 lines of routine \texttt{INFO} heartbeats, representation dilution lowers top-1 confidence to $75.0\%$ and inflates the prediction set to size 3, triggering automatic escalation.
\end{itemize}

\subsection{Positional Bias and Permutation Consistency}
While high-margin queries demonstrate robust permutation invariance (e.g., tool routing on \texttt{git\_ops} retains 100\% top-1 confidence regardless of candidate slot position), low-margin and sarcastic samples exhibit residual positional bias: shifting candidate option order can induce winner flipping. This empirical finding establishes the necessity of incorporating a \textbf{Permutation Invariance Dual Loss} ($\mathcal{L}_{\text{perm}} = D_{\text{JS}}(p(y \mid X, \mathcal{O}) \parallel p(y \mid X, \pi(\mathcal{O})))$) into future foundation iterations (Millennium-Jev 1.5B).

\section{Conclusion}
We presented \textbf{Millennium-Jev}, an open-source non-autoregressive System 1 decision foundation for AI agents. By combining Option Span Mean-Pooling, C++ Flash-SDPA zero-memory bidirectional attention, and Split-Conformal Tri-Gate clearance, Millennium-Jev provides sub-50\,ms deterministic reflexes with finite-sample mathematical safety guarantees. All artifacts are available at \url{https://github.com/sunziqin/millennium-jev}.
