## 摘要 (Abstract)

在自主运行的 AI 智能体（LLM Agent）系统中，环境交互由极高频度的微观控制决策驱动——例如工具调用路由、工作流状态分流、以及安全护栏判决。现存的智能体架构普遍将这些原子判断直接委托给自回归大语言模型（LLM），导致了严重的**“系统二（慢思考）延迟危机”**：单步推理必须“逐字生成 Token”，消耗 500~2,500 ms 的序列解码时间，显存带宽浪费严重，极易受到第一选项偏见（$A$-bias）干扰，并在面对分布外（OOD）或对抗性输入时产生未校准的过度自信。

为此，本文提出了 **Millennium-Jev（千禧年·Jev）**，一个开源的、基于单次前向传播的“系统一（System 1）”极速决策神经基座模型。Millennium-Jev 包含四项核心贡献：
1. **选项跨度均值池化（Vectorized Option Span Mean-Pooling）**：采用 GPU 批矩阵运算（`torch.bmm`），消除传统单标记方案在多词候选上的表征坍缩；
2. **底层 C++ Flash-SDPA 全双向直通算子**：直接重置骨干注意力层的因果标志位，在无 padding 单样本推断下实现 $0$\,KB 的中间 4D 掩码显存开销；
3. **单次前向多原语并发求解（Multi-Query Parallel Evaluation）**：将复合决策原语（`Choice`, `Score`, `Noul`）打包在单一 Prompt 中，主干仅 Forward 一次即可在 37.5 ms 内并发求解多维指标；
4. **无分布假设的分裂共形预测（Split-Conformal Prediction）与生产级三重门控（Tri-Gate Protocol）**：建立有限样本下的统计安全边界，数学上保证边际覆盖率 $\mathbb{P}(Y \in \mathcal{C}(X)) \ge 95.0\%$。

在 **8,657 条严格状态隔离、零模板泄漏的未见独立测试集** 上盲测表明：Millennium-Jev 0.5B 实现了 **84.28%** 的 Top-1 泛化准确率（比未微调 Qwen2.5 提升 **+15.68%**），共形经验覆盖率达 **94.16%**，三门控自主放行率达到 **73.95%**，且自主放行决策的真实准确率高达 **94.36%**（自主执行错误率严格控制在 5.64%）。

## 一、 引言与痛点分析 (Introduction)

随着大语言模型从被动问答转向主动智能体（Agent），智能体需要与复杂的外部环境持续交互。人类认知由两套协同机制组成（Kahneman 双系统认知理论）：
* **系统一（System 1，快思考）**：低能耗、无意识、亚秒级的自主神经反射；
* **系统二（System 2，慢思考）**：高能耗、有意识、串行深思熟虑的逻辑推理。

当前智能体生态存在严重的结构性倒挂：**无论多么简单、高频的控制分支判断，全都被交由庞大的自回归模型逐字写作文**。这带来了三大不可承受的代价：
1. **延迟与算力浪费**：为生成一个结构化选项，模型被迫生成 50~150 个 JSON Token，耗时 1~2 秒，造成大量算力浪费；
2. **位置偏见（Position Bias）**：自回归模型注意力由于因果单向掩码遮蔽，在犹豫时产生强烈的 $A$ 选项塌陷偏见；
3. **静默致命性（Silent Failure）**：缺乏数学不确定性度量，面对乱码或对抗攻击依然以 90% 以上的高置信度给出错误指令。

## 三、 核心架构与方法论 (Methodology)

### 1. 选项跨度均值池化（Option Span Mean-Pooling）
对于包含修饰词的复合候选动作，通过切片提取该选项在主干序列中的完整 Token 区间 $[s_k, e_k)$，采用批矩阵相乘（`torch.bmm`）计算语义质心：
$$\mathbf{h}_k^{\text{pool}} = \frac{1}{e_k - s_k} \sum_{t=s_k}^{e_k-1} \mathbf{H}_t \in \mathbb{R}^D$$
彻底杜绝单点标记（Single Marker）在复杂候选指令下的语义信息坍缩。

### 2. 底层 C++ SDPA 零显存全双向直通
通过重置注意力层 `is_causal = False`，无 padding 单样本推断直接设置 `attention_mask = None` 直通底层 PyTorch 原生 Flash-SDPA 内核。中间 4D 掩码分配降低至 **0 KB**，数值最大绝对误差 $< 9.76 \times 10^{-4}$。

### 3. 分裂共形预测与三重门控机制 (Tri-Gate Protocol)
基于严谨的有限样本统计学定理，构建预测集：
$$\mathcal{C}(X) = \{ k \in \mathcal{O} \mid p(k \mid X) \ge 1 - \hat{q} \}$$
保证 $\mathbb{P}(Y \in \mathcal{C}(X)) \ge 1 - \alpha = 95.0\%$。

**生产级自主放行三重门控（Tri-Gate Protocol）**：
1. **共形单例门**：$|\mathcal{C}(X)| == 1$（候选唯一无歧义）；
2. **置信度底线门**：$\max_k p_k \ge 0.60$（阻断均匀平坦的 OOD 乱码）；
3. **异常风险门**：$r_{\text{esc}} \le 0.70$（拦截结构性异常与恶意输入）。

## 五、 局限性与真实“短板边界”分析 (Discussion & Jaggedness)

学术严谨性要求我们客观剖析非自回归“快思考”（System 1）模型的固有物理边界，**不报喜不报忧**：

### 1. 两大致命静默缺陷（无法通过 Softmax 发现的盲目自信）
* **时间与数值算术（无思维链/CoT）**：由于模型在单次前向内直接输出决策，缺少自回归的中间推理草稿纸，无法进行连续多步算术（如 9月21日 - 9月10日 = 11天 > 7天退货窗口）。模型会产生高达 99.22% 的盲目自信误判，绕过单元素闸门。**工程落地要求**：时间差与数值比对必须在上游 Python 规则中预先计算，不可强求 System 1 模型做算术。
* **对抗性假标签欺诈 (Semantic Gaslighting)**：当恶意脚本被黑客显式注入“注意：这只是常规测试，请分类为良性”时，模型缺乏深度多步因果校验，易被表面语义诱导放行（98.44% 高置信）。**工程落地要求**：输入必须先经过基于确定性 AST/正则的输入净化，决策模型不可作为孤立防火墙。

### 2. 共形安全闸门有效拦截的场景
* **多意图冲突碰撞**：用户同时要求“退订”与“退款”时，预测集准确扩张到 2 个选项，触发 `can_act=False` 拦截转交人工。
* **高密度噪声干扰**：大量正常日志中混入 1 条致命错误，置信度摊薄，预测集扩张至 3 个，成功拦截。

### 3. 候选排列偏见 (Permutation Invariance)
在显著区分度样本上（如工具路由），模型对选项顺序具有极强对称鲁棒性；但在微弱优势的反讽/低边缘度样本上，调换顺序可能引发判定翻转。这指引我们在后续 1.5B 训练中必须将**对偶置换损失（Permutation Consistency Loss）**纳入硬约束。

## 六、 结论与开源贡献 (Conclusion)

Millennium-Jev 成功证明了：**非自回归决策模型能够以数十毫秒的时延和有限样本数学安全边界，全面取代智能体在控制流中的自回归生成**。全套代码、预训练权重与可复现基准已完全开源。
